LISTA DE TAREAS DE OPTIMIZACIÓN — cofa.com.ar
=========================================

Este documento lista todos los cambios a realizar para que la página de COFA cargue más rápido y funcione mejor en celulares. Cada tarea está explicada en lenguaje no técnico.


TAREA 1: Dividir el código para que cargue más rápido
------------------------------------------------------
Qué se hace: El código de la página se va a "cortar" en partes más pequeñas. Así, cuando alguien entra a la página, solo baja lo necesario para mostrar la pantalla inicial. El resto baja recién cuando se necesita.

Impacto: ALTO — mejora el tiempo de carga en celulares
Riesgo: BAJO — cambio seguro, no rompe nada existente

Archivos que cambian:
- src/RouterScreens.jsx


TAREA 2: Separar las librerías grandes en bloques independientes
-----------------------------------------------------------------
Qué se hace: Librerías como las que generan PDFs o integran inteligencia artificial son pesadas. Se van a separar en archivos propios que solo se descargan cuando el usuario realmente las necesita (por ejemplo, cuando pide un PDF).

Impacto: ALTO — reduce el peso del archivo inicial
Riesgo: BAJO

Archivos que cambian:
- vite.config.js


TAREA 3: Mejorar la carga de las fuentes de texto (tipografías)
--------------------------------------------------------------
Qué se hace: La página usa una fuente de Google que tiene muchos pesos (negritas, italic, etc). Se va a simplificar para que cargue más rápido y se le agrega "display=swap" para que el texto aparezca aunque la fuente tarde en descargar.

Impacto: MEDIO-ALTO — mejora el LCP ( Largest Contentful Paint )
Riesgo: BAJO

Archivos que cambian:
- index.html


TAREA 4: Imágenes con carga diferida (lazy loading)
--------------------------------------------------
Qué se hace: Las imágenes que están más abajo de la pantalla (carousel de imágenes, logos en el footer) se van a cargar recién cuando el usuario las scrollea hacia abajo. Así la página inicial aparece más rápido.

Impacto: MEDIO-ALTO
Riesgo: BAJO

Archivos que cambian:
- src/Components/ImageCarousel/ImageCarousel.jsx
- src/Components/Footer/Footer.jsx


TAREA 5: Optimizar los videos del carousel de la página principal
--------------------------------------------------
Qué se hace: Los videos del carousel estaban descargándose automáticamente antes de que el usuario los mire. Ahora solo van a cargar información mínima de los videos (metadata) hasta que el usuario los necesite ver. Además se cambia de "preload" a "prefetch" para que no bloqueen la carga de la página.

Impacto: MEDIO — mejora el tiempo de carga inicial
Riesgo: BAJO

Archivos que cambian:
- src/Components/Carrusel/Carrusel.jsx
- index.html


TAREA 6: Agregar etiqueta canonical y nuevos datos estructurados (SEO)
-----------------------------------------------------------------------
Qué se hace: Se agrega la etiqueta "canonical" para evitar contenido duplicado en Google. También se agrega un schema de "FinancialService" para que Google entienda mejor que COFA ofrece servicios financieros/préstamos.

Impacto: MEDIO — mejora SEO técnico
Riesgo: BAJO

Archivos que cambian:
- index.html
- src/Components/Seo/StructuredData.jsx


TAREA 7: Agregar tamaño explícito a 14 imágenes (mejorar CLS)
------------------------------------------------------------------
Qué se hace: PageSpeed detectó 14 imágenes sin atributos width/height. Cuando una imagen no tiene tamaño definido, el navegador no sabe cuánto espacio ocupa y eso causa "layout shift" (CLS). Se van a agregar width y height explícitos a todas las imágenes de la lista.

Impacto: MEDIO-ALTO — mejora CLS (Cumulative Layout Shift)
Riesgo: BAJO

Archivos que cambian:
- src/Components/ImageCarousel/ImageCarousel.jsx
- src/Components/Footer/Footer.jsx
- Multiple screen components (HomeScreen, CofaTipsScreen, FAQ, etc.)

Lista de imágenes detectadas sin dimensiones:

- /img/logo_cofa_tips.svg
- /img/cvs.svg
- /img/ssn-logo.svg (99.5 KiB — muy grande, verificar compresión)
- /Logo.svg (header/logo en varias páginas)

- /img/footer-aaip.webp


TAREA 8: Eliminar CSS que no se usa (11 KiB de ahorro)
------------------------------------------------------------------
Qué se hace: PageSpeed detecta 11 KiB de CSS sin usar en index.css. Se va a auditar qué estilos no se usan y limpiarlos. Puede requerir usar Chrome DevTools Coverage o purgecss.

Impacto: BAJO — solo 11 KiB
Riesgo: BAJO (CSS solo, no afecta JS)

Archivos que cambian:
- src/ (CSS files, puede requerir configuración adicional)
